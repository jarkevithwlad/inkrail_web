# Inkrail Web

Статический письменный стол на HTML, CSS и JavaScript с интерфейсом на русском языке. Не требует Node.js, npm, сборки, API-сервера или аккаунта. Шрифты, звуки и изображения поставляются вместе с приложением.

## Запуск

Запустите любой статический сервер из папки, где лежит `index.html`. Например, если установлен Python:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Откройте [http://localhost:8000](http://localhost:8000/). Через `file://` приложение не работает: браузер ограничивает загрузку JS-модулей и офлайн-кэширование. Нужен современный Chrome, Edge, Firefox или Safari. После первого успешного открытия Service Worker кэширует все файлы приложения для работы без сети по тому же адресу.

## Публикация на GitHub Pages

Поместите файлы приложения в корень нового репозитория: `index.html`, `sw.js`, `assets/` и остальные файлы должны лежать на одном уровне. В **Settings → Pages** выберите **Deploy from a branch → main → / (root)**. Сборка не нужна; подойдёт и любой другой статический хостинг с HTTPS.

## Что доступно

- Редактор писем с автосохранением, форматированием, Markdown-сокращениями, отменой и повтором. При запуске открывается конец последнего письма, а при первом запуске — конец приветственного текста.
- Каталог писем с поиском по заголовку и тексту, переименованием, корзиной и восстановлением в течение 30 дней.
- Настройки бумаги, полей, тиснения, шрифта, чернил, каретки, рабочего стола, ламп и звуков. Дневной, ночной режимы и режим фокуса.
- Восковые печати, импорт и экспорт текста и Markdown. Для PDF выберите **Сохранить как PDF…**, затем **Сохранить как PDF** в диалоге печати браузера. При необходимости включите печать фона и отключите колонтитулы.
- **Настройки → Данные**: скачать или импортировать JSON-копию писем, корзины и настроек. Импорт не перезаписывает письма; отличающиеся версии добавляются отдельно. Настройки оформления применяются из копии.

Библиотека хранится в IndexedDB текущего сайта и профиля браузера. Веб-версия не открывает Finder или Проводник и не переносит хранилище в произвольную папку: для переноса используйте резервную копию. Очистка данных сайта или завершение приватного сеанса может удалить письма. Синхронизации нет. Для переноса отдельных писем между веб- и настольной версиями используйте Markdown.

Если браузер перехватывает клавиатурную команду, выберите её через меню `…`.

## Обновление

Когда новая версия загрузится, появится кнопка **Обновить**. Она сохраняет изменения перед перезагрузкой страницы. Если вы ещё видите старый интерфейс без этой кнопки, один раз перезагрузите страницу без кэша (`Ctrl+Shift+R` или `Cmd+Shift+R`). Не очищайте данные сайта: там хранится библиотека писем.

При публикации изменений повысьте версию кэша в `sw.js` и добавьте новые файлы в список ресурсов. Новый кэш активируется сразу после полной загрузки. Код распространяется по лицензии [MIT](LICENSE). Лицензия шрифта и сведения об аудио находятся в [`notices/`](notices/).
